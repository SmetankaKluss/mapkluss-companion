# Support

MapKluss Companion supports the latest published builds for Minecraft
`26.2`, `1.21.11`, `1.21.8`, and `1.21.4`.

- Public bugs and feature requests: [GitHub Issues](https://github.com/SmetankaKluss/mapkluss-companion/issues)
- Project guides and announcements: [Telegram](https://t.me/mapkluss)
- Account and web editor: [mapkluss.art](https://mapkluss.art)
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md)

Before reporting a bug, reproduce it with the correct Companion JAR for the
Minecraft version and include the exact game, Fabric Loader, Fabric API,
Litematica, and MaLiLib versions. Remove account identifiers, server addresses,
coordinates, and access tokens from logs and screenshots.

Modified or redistributed builds are not supported.
