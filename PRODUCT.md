# MapKluss Companion

## Platform

Client-only Minecraft Java Fabric mod for 26.2, 1.21.11, 1.21.8 and 1.21.4.
It is a native game interface, not a web app or a web view.

## Users And Work

Map-art builders use saved Cloud art, install schemes, inspect materials,
scan maps and frames, align Lens previews and resume Two-layer construction.
Russian and English are equally supported. Mouse and keyboard are primary.

## Confirmed Constraints

Preserve current functions, permissions, cached data, request cancellation,
manual construction safeguards, opt-in telemetry and installed-file ownership.
No automatic world building, storage sorting or public Lens. Keep explicit
singleplayer MAP.DAT import. Never expose private fixtures in release JARs.

## Design Authority

Approved compact B composition and Pixel Workshop appearance are expressed
in DESIGN.md. Only seven dark editor themes; Amethyst default. Develop and
inspect the ordinary menu in Minecraft, never substitute an F8 mock screen.
Library visual review precedes further screen migration. Release is separate.
