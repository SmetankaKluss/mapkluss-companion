# Security policy

## Supported versions

Security fixes are provided for the latest published MapKluss Companion release on Minecraft `1.21.11` and `1.21.8`.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for authentication bypasses, token exposure, arbitrary file writes, unsafe archive extraction, private-art access, or other vulnerabilities that could harm users.

Include:

- affected Companion and Minecraft versions;
- clear reproduction steps;
- expected and observed behavior;
- impact and any safe proof-of-concept details;
- whether the issue is already being exploited.

Do not include real account tokens, private user data, service credentials, or another person's private art. Reports are reviewed on a best-effort basis. A coordinated disclosure date will be agreed upon for confirmed vulnerabilities.

## Scope

This repository covers the Fabric client mod. Website, account, Cloud, and API reports may still be submitted privately here when the issue is first observed through Companion; they will be routed to the correct MapKluss component.
