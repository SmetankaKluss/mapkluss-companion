# Приватность и сетевое поведение

MapKluss Companion — клиентский мод Minecraft. Он не требует серверного плагина и не открывает серверу Minecraft доступ к аккаунту MapKluss игрока.

## Локальные данные

В зависимости от используемых функций Companion может хранить внутри сборки Minecraft:

- сессию аккаунта MapKluss, полученную через вход по коду;
- язык и настройки маршрутизации сервисов;
- метаданные скачанных файлов и индекс установленных схем;
- ID карт, цветовые отпечатки, привязки частей арта и сжатые превью карт;
- настройки Lens;
- выбор по анонимной статистике и, только после согласия, случайный локальный идентификатор установки;
- планы Two-layer, якорь, выбранный ID карты и прогресс строительства;
- историю сканирования и Build Tracker.

Эти файлы остаются в папках `config`, `schematics` и других локальных папках сборки. Человек с доступом к файлам сборки может их прочитать. Выход через меню мода удаляет активную сессию MapKluss.

## Сетевые запросы

Companion обращается к сервисам MapKluss только для действий игрока или работы активной функции:

- вход по коду и проверка сессии;
- библиотека Cloud, арты, версии, коллекции, избранное и файлы;
- скачивание превью и файлов по временным ссылкам;
- отправка скана, явно запущенная игроком;
- синхронизация Build Tracker;
- сессии Lens, presence, revisions, превью и Realtime-сигналы, пока Lens активен;
- проверка готовности gateway и безопасный резервный маршрут;
- один ограниченный запрос к публичному GitHub Releases API при запуске для проверки обновлений.

Неактивный Lens не выполняет фоновые сетевые запросы и не пишет данные на диск. Активный Lens использует ограниченный heartbeat, Realtime как основной канал и более редкий восстановительный polling.

Проверка обновлений не отправляет аккаунт MapKluss, арт, мир, сервер, инвентарь или игровой процесс. GitHub получает только обычные сетевые метаданные HTTPS-запроса. Последняя показанная версия хранится локально, чтобы одно уведомление не повторялось.

## Необязательная анонимная статистика

При первом запуске Companion спрашивает, можно ли делиться анонимной статистикой. До явного согласия мод не создаёт идентификатор телеметрии и не отправляет запросы аналитики. Выбор можно изменить в разделе «Аккаунт». При отключении локальный идентификатор удаляется.

После согласия Companion может отправлять только одно из событий: запуск, завершённый вход, открытие библиотеки, установка схемы, запуск Lens или создание Tracker. Вместе с событием передаются только версия Companion, версия Minecraft, язык интерфейса и общее семейство операционной системы.

В статистику никогда не попадают аккаунт, сервер или мир Minecraft, координаты, арт, ID карты, имя файла, содержимое инвентаря или текст ошибки. Сервис сразу заменяет случайный идентификатор установки солёным хешем, который меняется каждый день по UTC. Исходный идентификатор и IP-адрес не записываются в таблицы аналитики. Отдельные события хранятся не более 30 дней; для долгого хранения остаются только дневные суммарные счётчики.

## Что остаётся только на устройстве

Companion не отправляет координаты и якоря Two-layer, прогресс демонтажа, привязки AutoFrame, локальный кеш превью карт и обычное содержимое инвентаря. Мод не ставит и не ломает блоки автоматически.

## Удаление аккаунта

Cloud-данные и аккаунт удаляются через [mapkluss.art/cloud](https://mapkluss.art/cloud). Удаление мода не удаляет серверные данные аккаунта. Чтобы убрать локальные данные Companion, отдельно удалите его папку конфигурации внутри сборки Minecraft.

## Логи и отчёты

В логах Minecraft могут находиться технические ошибки, несекретные идентификаторы и имена файлов. Перед публикацией логов проверьте и удалите личные данные. Никогда не публикуйте токены аккаунта, коды входа, приватные арты, адреса серверов и личные пути файловой системы.
